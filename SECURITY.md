# Security

Report security problems privately to support@vibevo.io. Do not place tokens, credentials or private account records in public issues.

This package declares remote connection metadata only. It contains no runtime hooks, local executable, API key, client secret or account credentials. The public OAuth client identifier is not an account credential.

Review the actual account and requested permissions when connecting. Enable write access only when needed and review operations that change account access, publish information, delete records or consume existing monitoring credits. The hosted connection excludes payment, withdrawal, credit-purchase and funded placement operations.
